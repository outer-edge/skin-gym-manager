# Skin Gym Client Manager

A modern client management application for tracking memberships, purchases, and analytics for a skin care membership program.

## Features

- **Member Tracking**: Track 57 active members with membership details
- **Purchase History**: Monitor recent product purchases from clients
- **Analytics Dashboard**: View monthly growth and membership statistics
- **Modern UI**: Clean, Gumroad-inspired interface design

## Tech Stack

- **Backend**: Node.js, Express.js
- **Database**: SQLite
- **Frontend**: Vanilla JavaScript, HTML5, CSS3
- **Styling**: Inter font family, modern design system

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm start
```

Visit `http://localhost:3000` to view the application.

### CLI Version

```bash
node cli.js
```

### Populate Sample Data

```bash
node populate-data.js
```

## Deployment

This application is configured for deployment on Vercel. Simply connect your GitHub repository to Vercel for automatic deployments.
